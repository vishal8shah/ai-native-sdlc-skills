# Security and data reporting

These skills provide instructions and local helper tools. They do not authenticate approvals, enforce production permissions or provide a production deployment integration.

If a defect could expose sensitive information or permit an unsafe action, avoid posting credentials, customer data, exploit details or employer records in a public issue. Use the repository's private vulnerability reporting if it is enabled; otherwise contact the maintainer through their public profile to agree a private reporting channel first.

For ordinary non-sensitive helper bugs, a synthetic reproducer in a bug report is useful. Include the affected version, environment and observed result.
